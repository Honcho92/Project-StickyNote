## StickyNotes 1.0.0

Pin notes to apps, webpages, and anything with a window. A note auto-shows when
its target window is focused and tucks away when you switch off. Notes with no
pins act like classic always-on-top stickies.

### Download

- **StickyNotes_Setup.exe** — recommended. Installs per-user (no admin needed),
  adds a Start Menu shortcut, optional desktop / start-at-login shortcuts, and a
  clean uninstaller.
- **StickyNotes.exe** — the standalone app; just run it, nothing to install.

No Python or other dependencies required. Requires Windows 10/11.

### Good to know

- Your notes are saved in `%APPDATA%\StickyNotes` and survive updates.
- This build isn't code-signed yet, so Windows SmartScreen may show an
  "unknown publisher" prompt on first run — click **More info → Run anyway**.
