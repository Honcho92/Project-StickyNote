# StickyNotes 1.2.0

## New: Voice notes (on-device transcription)

Every note now has a microphone button. Click it, speak, click again to stop —
your words are transcribed straight into the note, powered by whisper.cpp
running entirely on your PC. No cloud, no account, nothing leaves your machine.
The voice model downloads once (~140 MB) on first use, then works fully offline.

- Free: record clips up to 15 seconds — great for quick voice memos.
- Pro: unlimited recording length.

## Also in this release

- More robust license-key validation.
- Version bump to 1.2.0.

## Install

Download **StickyNotes_Setup.exe** below and run it (per-user install, no admin
needed). Windows may warn about the unsigned installer — click
**More info -> Run anyway**. A signed release is on the way.
